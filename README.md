# 🏥 AI Healthcare Assistant

An intelligent healthcare web application that predicts diseases using Machine Learning and provides AI-powered healthcare recommendations.

---

## 📌 Project Overview

The AI Healthcare Assistant is designed to help users analyze their symptoms and predict possible diseases using Machine Learning models. It also includes an AI-powered healthcare assistant that provides personalized health recommendations and maintains patient history for future analysis.

---

## 🚀 Features

- 🔐 User Login & Registration
- 🩺 Disease Prediction using Machine Learning
- 🤖 AI Healthcare Assistant
- 📊 Dashboard with Patient Information
- 📜 Prediction History
- 👤 User Profile Management
- 💡 Personalized Health Recommendations
- 📱 Responsive User Interface

---

## 🧠 Machine Learning Models

The project compares multiple Machine Learning algorithms:

- Random Forest
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Multi-Layer Perceptron (MLP)

The MLP Classifier achieved the highest accuracy and was selected as the final prediction model.
